## Task 1 (25 points)

## Task 2 (20 points)

1. Use `script` to create **task2.txt**
2. Create an environment variable `fruit` and set it to your favorite fruit.
3. `echo` the value of fruit to the screen
4. Set PS1 to be just your username and the working directory, followed by a >



---

## Task 3 (15 points)

1. Use script to create **task3.txt**.
2. Untar/ungzip `animals.tgz`
3. Create a new file: `A.tgz` containing all files from `animals.tgz` that start with the letter A.

---

## Task 4 (15 points)

1. Create two named screens. What you name them is up to you.
2. Make sure you are detached from your screens.
3. Use `script` to create **task4a.txt**
4. List all of your screens.
5. End the script.
6. End all of your screens.
7. Use `script` to create **task4b.txt**
8. List all of your screens.
9. End the script.

---


## Task 5 (25 points)

1. Create **task5.sh**, a bash script to do the following:
    1. Greet the user with a message of your choice
    2. Change directories to the directory given as the first command line argument
    3. Ask the user for a file name
    4. `touch` the filename input by the user
